# Symbol set attribution

The Sign Setu symbol set starts from two open symbol libraries. Edited and newly drawn symbols are released under the same licence, CC BY-SA 4.0.

| Folder | Source | Version | Licence |
| --- | --- | --- | --- |
| `openmoji/` | OpenMoji, HfG Schwäbisch Gmünd (https://openmoji.org) | 17.0.0 | CC BY-SA 4.0 |
| `mulberry/` | Mulberry Symbols, Steve Lee (https://mulberrysymbols.org) | commit 9cbab9f (2026-08-21) | CC BY-SA 4.0 |

Licence text: https://creativecommons.org/licenses/by-sa/4.0/

`map.json` maps each card ID to its source file. To replace a symbol with an original drawing, add the SVG under `sign-setu/` and point the card at it.
