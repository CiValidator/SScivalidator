# Governance Pack

Documents for the department, the legal adviser and the CERT-In empanelled auditor. They are not needed to write code.

Every document describes release 1 as built: offline, no server, the stage with the camera mirror (D-20) and the code-drawn characters (D-21). Parts that apply only with the release 1.1 gateway are marked as such.

Still needing a decision outside the team: the DPDP Rule 8(3) opinion ([DPIA](08-privacy-dpia.md) §4.1, R-19), the rooted-device policy (T-19), and the department's names, contacts and channel in the [privacy notice](policies/privacy-notice.md).

The [content review record](forms/content-review-record.md) is generated from the content files by `python tools/content/review_record.py`; regenerate it with every content change so reviewers sign the content that ships.
