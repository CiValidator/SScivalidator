# 18. Officer User Guide and Quick Card

## Quick card (print on one side, A6)

```
SIGN SETU - QUICK CARD
It helps you talk. It is NOT an interpreter. Signs it reads can be wrong.

1. Calm place. Get to their level. Tap FLIP if they face you.
2. Choose THEIR language.
3. Start: "You are safe" > "Are you hurt?" > "Water?" > "Food?" > "Toilet?"
4. One question. Wait.
5. Trust pictures and YES/NO most. Sign result Medium/Low? Ask again.
6. No network? Preset questions, pictures, drawing still work.
7. Never ask what happened first. Never record a statement here.
8. Done: EXPORT to official record if needed > END SESSION.
   Send passphrase separately from the file.
9. Phone lost? Tell your supervisor now.
Child in distress: Childline 1098 or 112.
```

## Guide

| Task | How |
| --- | --- |
| Start | Open app, unlock with fingerprint or PIN. Last unfinished session resumes; otherwise a new one starts. |
| Set language | Top-left language button. Sets captions and ISL for the subject. |
| Face the subject | **Flip** turns their half upside down so they read it from across. **Focus** shows only their half; tap the top edge to return. |
| Preset question | Tap a group (Safety, Health, Needs, More), then a question. It shows instantly, even offline. |
| Your own question | Type and tap send, or hold the mic, speak, release, check the text, tap send. |
| Show a picture | Board icon, search or browse, tap a picture to show it. Star it to keep it handy. |
| Read their answer | Answers appear under your input: picture with label, recognised sign with High/Medium/Low, or drawing. |
| Sign recognition | Camera button. Light on their hands, phone steady at chest height. Green dot means camera is on. Turns off by itself after a minute with no hands. |
| Drawing | Pen button. They draw; you tap **Save to notes**. |
| Notes | Notes icon; type what you learnt. Avoid names and addresses unless needed now. |
| End | Menu, **End session**. Export if needed (you get a one-time passphrase), then **Clear**. |
| Settings | Text size, avatar speed, auto-delete time, clear all data. |

## Troubleshooting

| Message | Meaning | Do |
| --- | --- | --- |
| Offline | No network | Use presets, pictures, drawing |
| Sign not available | No ISL for those words | Point to caption and pictures |
| Service busy | Server slow | Tap cancel, use pictures |
| Update required | App too old for the server | Update from Mobile Seva or department channel |
| Camera unavailable | Permission off or camera in use | Settings, permissions, or use pictures |
